# dcp-types

Shared protocol types for [DCP (Desktop Context Protocol)](https://github.com/your-org/dcp).

Includes:
- JSON-RPC 2.0 request/response types
- Context selectors and snapshot types
- Capability and permission model
- Event types for all desktop events
- Platform data structures (WindowInfo, ProcessInfo, etc.)
- Vision/OCR types
- Automation command types

## Usage

```toml
[dependencies]
dcp-types = "1.0"
```
